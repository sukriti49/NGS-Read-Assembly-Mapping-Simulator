# DNA Assembly & Mapping Simulator 

A beginner-friendly Python project that simulates basic steps of an NGS
sequencing workflow.

## Objective

The goal of this project is to understand how sequencing reads are generated,
assembled, and mapped back to a DNA sequence through a simple simulation.

## What the Project Does

1. Generates a random DNA sequence using A, T, G and C.
2. Generates random sequencing reads from the reference sequence.
3. Creates overlapping reads.
4. Uses overlaps to simulate sequence assembly.
5. Maps the generated reads back to the assembled sequence.

## Concepts Practiced

- DNA sequences
- Sequencing reads
- Random sequence generation
- Read length
- Overlapping reads
- Sequence assembly
- Read mapping
- Python loops and strings

## Workflow

Random DNA Sequence > Generate Sequencing Reads Find Overlaps > Assemble Reads > Map Reads Back
